# Hartman-universe
Масштабный проект по созданию реальной Вселенной из цифровой Вселенной. Исследование, моделирование и разработка концепций перехода от цифровой реальности к физической, объединяющих искусственный интеллект, программирование, физику и технологии будущего. Цель проекта — исследовать возможность создания новой реальности на основе цифровых моделей.
